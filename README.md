# Calibra Studio — studio.calibraautomation.com

Web de los servicios llave en mano de Calibra (agencia de automatización con IA).
La plataforma SaaS vive en https://calibraautomation.com (repo `nuriadev-droid/calibra-web`).

Se publica con GitHub Pages: cada push a `main` ejecuta `build-static.js --dominio https://studio.calibraautomation.com`.
